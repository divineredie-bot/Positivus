# Positivus

Адаптивный сайт, свёрстанный по макету Positivus.

## Особенности

- Адаптивная вёрстка для мобильных и десктопных устройств
- Методология БЭМ
- Организация стилей с использованием SCSS
- Семантическая HTML-разметка
- Адаптивное меню
- Анимации и интерактивные элементы

## Технологии

- HTML5
- SCSS
- JavaScript
- БЭМ
- CSS3
- Flexbox
- CSS Grid
- Media Queries
